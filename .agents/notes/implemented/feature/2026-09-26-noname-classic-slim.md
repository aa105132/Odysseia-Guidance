# Agent Note: 三国杀经典模式物理精简

Status: implemented

## Problem

用户要求仅保留经典模式并明确拒绝完整资源包。只隐藏外层预设仍会加载旧配置和全量素材，不能满足要求。

## Decision

以固定上游 `1bbf1759962f326e2c53d672b16ba0e214918c2d` 的 `identity/normal`、33 名标准武将和标准牌为边界。`prepare.mjs` 必须向空目录按白名单构建；默认挂载目录改为 `data/noname/classic-dist`。保留单机、好友联机以及 2/4/6/8 人入口，不改大厅设计、其他游戏或货币结算。

引擎配置加载后纠正旧模式、扩展包及续局标记，限定菜单目录和持久化写入；联机房间列表与房号加入都检查经典标准双包。标准武将依赖的 xunxun、wangxi、reyicong、shenzhi 从固定源码提取，不加载 refresh/sp 运行包。共享引擎登记的 zhanfa 是内置展示目录，不是标准牌堆；测试直接检查实际牌堆只包含标准牌。

真实启动发现并补齐 game/update.js、默认背景、手牌占位、四势力图标；保留空表情目录供只读目录协议查询。默认 card_style 落到已有 default.css，联机动态模式加载直接使用编译入口，避免不必要的目录入口 404。测试处理首次版本公告和自动确认选将按钮消失的竞态，不修改游戏技能规则。

## Alternatives considered

- 全量资源只隐藏菜单：用户明确拒绝。
- 在旧完整目录上覆盖：遗留资源使精简失效，因此拒绝非空输出。
- 引入整个 refresh/sp 运行包：只为四个技能却带入扩展武将，不采用。
- 随意缩成 2008 年 25 将：会改变现有标准包语义，不采用。

## Consequences

发布资源明确缩小，单机与好友联机已跑通；共享引擎仍包含未启用玩法的公共代码，未为极限体积重写上游。源码子集与适配脚本随包保留，refresh/sp 源码只供技能提取，不作为运行包；重建说明仍使用固定 checkout，未验证解压源码子集离线独立重建。

本地检查不是所有武将技能的多局语义测试，也不是真实 Discord WebView 或全面断线恢复验收。生产仍未更新；未来发布须独立基于当前生产版本组装，保留已部署的退款修复，不夹带本地主分支其他工作。
